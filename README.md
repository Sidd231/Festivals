# Festive Demand Forecast AI

An AI-powered demand forecasting application that uses a trained XGBoost regression model to predict inventory demand based on store, item, date, and festival-related factors.

## Tech Stack

- Python
- Flask
- XGBoost
- Scikit-learn
- HTML
- CSS
- JavaScript
